# Tracking Surat — Web Application

Tracking Surat is a web-based application for managing and tracking official letters within an organization. It helps users handle letter-related processes, from submitting documents to checking their status, through a centralized web interface.

I worked on this project during my internship at PT Asri Dharma Sejahtera, where I was involved in frontend development and UI implementation. My work included building and adjusting several pages, working on forms and navigation components, and improving the overall layout to make the application easier to use.

## What I Worked On

- Developed and adjusted frontend pages for the application.
- Built interface components such as dashboards, forms, tables, and navigation menus.
- Worked on the interface for document submission and letter tracking.
- Improved page layouts and styling to make the interface more consistent.
- Worked with the existing application structure to integrate frontend changes.

## Features

- Dashboard for accessing application information.
- Letter submission and document upload.
- Letter status tracking.
- User management.
- Account recovery through OTP verification.
- Deleted document management.

## Technologies

HTML, CSS, JavaScript, PHP, and Bootstrap.

Working on this application gave me a better understanding of how frontend development works within an existing web application. I also gained experience adapting interface designs, working with existing code, and collaborating on the development of a web-based system.
